# AshenCrown
Ashen Crown — 2D top-down MMORPG в пиксель-арте. Бой: выбор цели кликом, автоатака, 5 умений с кулдаунами. Классы (MVP): 2 (например, воин и маг). Мир: 1 город, 2 охотничьи зоны, 3 типа врагов + 1 босс. Системы: инвентарь, экипировка, 5 квестов, чат, группы. Не в MVP: крафт, гильдии, аукцион, PvP, питомцы.
